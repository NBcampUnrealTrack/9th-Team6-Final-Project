2026-10-28 지도/포탈/창고 뚜껑 작업 완료
커밋·푸시·PR은 수행하지 않음. 기존 작업 변경분 보존.

- 기존 BP_ICWarpStone 재사용. 테스트맵 좌/중/우에 WRP_TEST_01~03 설치.
- 실제 맵을 위에서 2048×1024 정사영 촬영. AI 이미지 생성 사용 없음.
  조명 대신 실제 재질 색상 패스로 촬영하여 지도에서 어두워지지 않도록 함.
- T_TestMap_Overview, WBP_IC_Map, HUD WBP_IC_Minimap 연결.
- M / Xbox View로 지도. 포탈에서 F / Xbox X도 지도 열기.
- 지도 마커 클릭 또는 방향키+Enter / Xbox A로 선택 및 이동.
- DT_IC_MapPresentation에서 비용 500G, 로딩 1.2초 및 자동 해금 설정.
- DT_IC_Map의 이미지/좌표축/범위와 실제 배치된 Warp/Anchor 연동.
- 파티 워프는 기존 ICPartyWarpComponent 사용. 성공 시에만 과금.
- 이동 중 닫기 및 중복 요청 차단. 골드 부족 시 위치/골드 유지.
- 개인/NPC 창고 CDO 및 배치 인스턴스 OpenRotation.Roll=-105로 통일.
- Xbox View는 기존 임시 인벤토리 바로가기 대신 지도 열기로 변경.
- 지도 영어 문구도 번역 목록에 추가. 총 1281개, 번역/형식 인자 검증 성공.
