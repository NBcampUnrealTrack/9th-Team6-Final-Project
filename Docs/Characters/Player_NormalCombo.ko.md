# 플레이어 직업별 일반 공격

- 남녀 플레이어의 검·활·지팡이·완드에 각각 3단 콤보 몽타주를 연결한다.
- 클릭마다 한 타를 실행하고, 공격 중 추가 클릭 1회는 다음 타로 예약한다. 3타 뒤에는 1타로 순환한다.
- 연계 시간 0.8초가 지나거나 무기가 바뀌거나 공격이 취소되면 1타부터 시작한다.
- 각 타의 피해 계수는 1.0 / 1.1 / 1.4다. 공격 속도에 맞춰 모션·타격 타이밍이 함께 조절된다.
- 몽타주의 타격/발사 Notify와 시간 기반 처리는 동일한 타격 ID를 사용하므로 중복 타격하지 않는다.

| 직업 | 일반 공격 | 최대 투사체 이동 거리 | 시각 효과 |
| --- | --- | --- | --- |
| 검사 | 전방 부채꼴 베기 | 실제 장착 검 길이 + 기존 보정 | 교차 베기 궤적과 실제 범위 표시, 3타 금색 |
| 궁수 | 물리 투사체 | 3,000cm | 금색 화살과 궤적 |
| 마법사 | 마법 투사체 | 1,800cm | 파란 마력탄과 궤적 |
| 힐러 | 마법 투사체 | 1,800cm | 초록 성광탄과 궤적 |

원거리 일반 공격은 적 또는 장애물 한 곳에 맞으면 종료된다. 아군과 자기 무기는 통과하며, 느린 프레임에서도 지정된 거리를 넘어서 이동하지 않는다. 선택 대상과 관계없이 발사 순간의 **화면 중앙**을 조준한다. HUD 중앙의 십자 조준점은 원거리 무기를 사용할 때 표시된다.

마법사와 힐러는 같은 3단 캐스팅 모션을 사용하며, 자유로운 왼손의 손바닥 소켓에서 마력탄이 나온다. 활도 위·아래 활대 끝이 아니라 왼손이 잡은 화살 받침 위치에서 발사한다. 카메라 중앙에서 적/장애물까지 구한 지점으로 손의 투사체가 수렴하므로 카메라와 손의 위치 차이, 높낮이가 함께 반영된다. 설정의 **조준점 거리 보정**을 끄면 최대 사거리의 화면 중앙을 조준한다. NPC와 동료의 자동 전투는 기존 대상 조준을 유지한다.

`Tools/Characters/setup_player_combo.py`는 원본 애니메이션을 보존하면서 플레이어 스켈레톤별 모션, 몽타주, 이펙트 재질, 직업 CSV 및 DataTable을 갱신한다. 재생성 시 기존 이동·스킬·물리·무기 보정은 유지한다.

검증: `IC.Combat.NormalAttack.ComboAnimations`, `IC.Combat.NormalAttack.RangedTravelAndDamage` 통과. 남녀·4직업 콤보, 예약 입력, 시간 초과 초기화, 10m 명중, 중복 발사 방지, 저프레임 최대 거리, 벽 충돌을 확인했다. 리타겟 도구 실행 중 원본 Archer 데모의 기존 누락 Pose Asset 오류가 출력되지만 플레이어 24개 몽타주 생성과 런타임 검증은 완료됐다.

`IC.Combat.NormalAttack.ScreenCentreAndHands`는 남녀·3원거리 직업의 실제 손 소켓 발사, 무기 끝 발사 배제, 발사 전 카메라 회전 반영, 높은 조준점의 적 명중, 화면 밖 선택 대상의 자동 명중 방지를 검증한다.

화면 중앙 조준 변경 후 기본 빌드와 관련 프로젝트 테스트 22개가 통과했다(`Saved/CentreAimTests.log`). 투사체의 초기 속도를 월드 좌표로 적용해 생성 시 회전이 중복되는 문제를 수정했고, 거리 계산 뒤 이동하도록 틱 순서도 정리했다. 최종 실제 PIE의 24개 콤보 캡처에서 중앙으로 향하는 투사체와 손 발사를 확인했으며 틱 순환 경고는 없다.

`Tools/Characters/review_player_combo.py`로 실제 장착 무기를 사용하는 격리 PIE에서도 남녀·4직업·3타를 모두 재생했다. 각 타의 활성 몽타주와 화면에 나온 베기/투사체를 확인한 24개 캡처 및 결과는 `Saved/PlayerComboLiveReview`에 저장된다.
