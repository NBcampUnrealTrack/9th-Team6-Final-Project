[현재 반영된 내용]
- Xbox가 기본 컨트롤러입니다. Nintendo는 선택 옵션입니다.
  RT 공격, LT 달리기/회피, RB 무기 순환, LB 대상 지정,
  X 상호작용, Y 낚시, A 점프/확인, B 취소, LT+XYBA 스킬.
  십자키 퀵슬롯 → L스틱 파티 대상 → A 사용. 키보드와 함께 사용 가능.
- Tab 대상 지정 후 일반 공격 입력 시 동료 3명에게 지시합니다.
  기존 살아 있는 적과 싸우면 그 적을 마무리한 뒤 대기 대상에게 이동합니다.
- 닭 F: 사망 애니메이션 후 숨김 및 획득 UI. 닭고기 1, 달걀 50%로 1~4.
- HUD 퀵슬롯 4칸 상시 표시. 아이콘 누락으로 슬롯 자체가 숨던 문제 수정.
- 사망 시 전체 오디오 정리/음소거. 살아 있는 저장 불러오기 시 정상 복귀.
  저장 복원 중 피격 효과음/피격 몽타주 재생을 차단합니다.
- 개인/NPC 창고에 원본 팩 뚜껑 추가. 개방 애니메이션 후 기존 40칸 창고 UI.
  UI를 닫으면 상자도 닫힙니다.
- 책장/옷장은 F로 직접 획득. 기본은 가구별 세이브당 1회이며 DT로 재획득 시간 설정 가능.
- 수면은 후속 요청으로 약 2초의 짧은 연출로 교체했습니다. 긴 진입/기상 클립과 위치 보간은 사용하지 않습니다.
  암전 중 침대 자세/카메라 전환 → 루프 0.8초 → 암전 중 기상/카메라 복귀. Fade 0.25초, BlackHold 0.08초.
- 남녀 빈손 점프/공중/착지를 Manny 점프로 교체. 기존 지상 이동과 무기 점프 유지.
- 한국어/영어 설정 및 입력 안내 방식/패드 배치 설정 추가. WBP 재생성.
  기존 한국어 원문 1273개 영어 번역. StringTable/FText 원문과 형식 인자 보존.
  실행용 English.json/NativeKeys.json을 UFS 패키징에 포함.
  번역 결과는 런타임 Polyglot GetText를 사용하여 에디터 전용 API에 의존하지 않습니다.
