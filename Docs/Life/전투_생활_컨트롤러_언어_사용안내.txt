전투 · 생활 · 컨트롤러 · 언어 변경 안내

[Tab 대상 지정 / 동료 지시]
화면 앞의 적을 바라보고 Tab을 누르면 대상을 지정합니다. 다시 누르면 화면 앞의 다른 적으로 순환합니다.
지정 가능 거리 2500cm, 유지 거리 3000cm이며 벽에 가려진 적은 선택하지 않습니다.
거리와 가림 허용 시간: /Game/IsekaiClass/Data/DataTable/Settings/DT_IC_CombatSettings
Tab으로 지정한 뒤 일반 공격을 입력하면 활성 동료 3명에게 해당 적을 지시합니다.
동료가 다른 살아 있는 적을 이미 공격 중이면 현재 적을 끝내고 지시받은 적에게 이동합니다.
추가 지시는 대기 대상을 최신 지정 대상으로 바꿉니다. 지시 대상이 먼저 죽거나 사라지면 자동으로 정리합니다.

[닭]
가까이 다가가 닭을 바라보고 F: 사망 애니메이션 → 사라짐 → 획득 UI.
닭고기 1개 보장, 달걀은 50% 확률로 1~4개입니다. 가방이 가득 차면 기존 초과 아이템 처리로 보존합니다.
/Game/IsekaiClass/Data/DataTable/Life/DT_Ranching : DeathAnimation, SlaughterSeconds
/Game/IsekaiClass/Data/DataTable/Rewards/DT_IC_DropTable : DRP_R01_CHICKEN 수량·확률

[개인 / NPC 창고]
기존 상자 본체 SM_chest_01 + 동일 팩의 뚜껑 SM_chest_03과 MI_chest_Inst를 사용합니다.
F를 누르면 뚜껑이 열린 뒤 기존 40칸 창고 화면을 띄웁니다. 창을 닫으면 뚜껑도 닫힙니다.
열리는 시간·힌지 위치·회전은 BP의 ChestPresentation에서 변경합니다.
BP_IC_PlayerStorage : /Game/IsekaiClass/Life/Home/Blueprints
BP_IC_NPCChest : /Game/IsekaiClass/NPC/Blueprints/Containers

[책장 / 옷장 / 이후 추가 가구]
NPC 책장과 옷장은 F로 바로 보상을 받고 창고 화면은 열지 않습니다. 기존 호감도 200 접근 조건은 유지합니다.
책장은 엘릭서 중 1개, 옷장은 포션 또는 씨앗 중 1개를 기본 보상으로 연결했습니다.
기본은 가구마다 저장 게임당 1회 획득입니다. 재획득하려면 RefillGameMinutes에 양수 게임 분을 입력합니다.
/Game/IsekaiClass/Data/DataTable/Life/DT_IC_FurnitureLoot : Bookshelf / Wardrobe
DropTableID로 실제 보상 목록 연결. /Rewards/DT_IC_DropTable에서 아이템·수량·가중치 편집.
새 BP는 AICNPCContainerActor를 상속하고 bPickupOnly=True, FurnitureLootRow를 지정하세요.
OwnerNPCID와 서로 겹치지 않는 ContainerID를 반드시 지정하세요. ContainerID가 보상 획득 저장 키입니다.
bPickupOnly=False이면 기존 NPC 창고로 동작합니다.

[수면 / 빈손 점프]
남녀 모두 별도 리타기팅한 수면 루프를 사용합니다. 긴 눕기/기상 클립과 위치 보간은 재생하지 않습니다.
짧은 암전 중 침대 자세로 전환 → 수면 자세 0.8초 → 다시 암전 중 기상 → 원래 카메라로 복귀합니다.
각 전환은 어두워짐 0.25초, 검정 화면 0.08초, 밝아짐 0.25초로 전체 약 2초입니다.
/Game/IsekaiClass/Data/DataTable/Life/DT_IC_SleepPresentation : Default
EnterSeconds(에디터 표시 Rest Pose Seconds)는 수면 자세를 보여주는 시간입니다. Fade/BlackHold 값은 두 전환에 각각 적용됩니다.
CameraOffset / CameraFocusOffset / FieldOfView : 침대 기준 카메라 조절.
남녀 프로필 DA_ANIM_PLAYER_M/F의 Sleep / SleepMeshTransform으로 자세·정렬 조절. SleepEnter/Exit 에셋은 보존만 합니다.
빈손 점프는 Manny의 MM_Jump / MM_Fall_Loop / MM_Land를 새로 리타기팅해 교체했습니다.
기존 걷기·뛰기와 무기를 든 점프는 유지합니다.

[소리 / 불러오기]
플레이어 사망 시 재생 중 소리를 정리하고 전체 게임 오디오를 음소거합니다.
불러오기 시 이전 소리와 진행 중 몽타주를 정리하고 복원 과정의 피격 효과음을 차단합니다.
살아 있는 저장으로 복귀하면 사용자 음량 설정과 지역/전투 BGM 선택을 다시 사용합니다.

[퀵슬롯]
HUD 네 칸은 빈 칸도 표시합니다. 등록한 소비품의 DT 아이콘과 실제 사용 가능한 개수를 표시합니다.
아이콘이 없다는 이유로 등록된 아이템 칸 전체를 숨기지 않습니다.
기존 비어 있던 포션·음식·엘릭서·확장권 아이콘만 프로젝트 내 임시 아이콘으로 채웠습니다.
외형 변경: /Game/IsekaiClass/Data/DataTable/Items/DT_IC_Item 의 Icon

[컨트롤러 기본: Xbox]
L스틱 : 이동 / 아이템 사용 대상 선택 중에는 자신·동료 선택
R스틱 : 카메라 / R스틱 클릭 : 대상 지정 해제
RT : 일반 공격
LT : 비전투 중 누르고 달리기 / 전투 중 단독 입력은 뗄 때 회피
RB : 무기 순환 / LB : Tab 대상 지정
X : F 상호작용 / Y : H 낚시 / A : 점프·확인 / B : ESC·취소
LT+X : Q 플레이어 스킬
LT+Y : E 동료 1 스킬
LT+B : R 동료 2 스킬
LT+A : T 동료 3 스킬
십자키 위/오른쪽/아래/왼쪽 : 퀵슬롯 1/2/3/4
퀵슬롯 선택 후 L스틱으로 대상을 고르고 A로 사용, B로 취소.
Start : 메뉴 / View : 지도
창고 화면 LB/RB : 창고·인벤토리 쪽 전환. 십자키 : 칸·수량·버튼 선택.
상점 A : 장바구니 담기, X : 결제, B : 취소.
설정 > 조작 · 키 설정 : 입력 안내 자동/키보드/컨트롤러 및 Xbox(기본)/Nintendo 배치 선택.
Xbox가 프로젝트 기본입니다. Nintendo는 선택 옵션이며 기본 배치로 사용하지 않습니다.
키보드와 컨트롤러 입력은 함께 사용할 수 있습니다. 조작 장치 표시는 입력 차단 옵션이 아닙니다.

[언어]
설정 > 기타 > 언어 : 한국어 / English 선택 후 적용 · 저장.
언어는 세이브와 분리된 사용자 설정으로 저장합니다.
한국어 StringTable 원문을 유지하고 영어 FText 번역을 연결했습니다. 메뉴·설정·아이템·레시피·스킬·퀘스트 등의 기존 원문 1281개를 정리했습니다.
영어 번역 원문 목록: Data/Localization/English.csv
번역 수정 소스: Data/Localization/English_*.txt (SourceCatalogue의 고정 번호), English_*.tsv (용어·문장)
재생성: Tools/Localization/compile_english.py
번역 파일을 재생성한 뒤에는 에디터 또는 게임을 다시 실행하면 변경 내용이 반영됩니다.
새 문구 추가: Tools/Localization/extract_english_sources.py --append 실행 후 번역을 추가합니다. 기존 번호는 유지됩니다.
실행용 파일: Content/IsekaiClass/Localization/English.json, NativeKeys.json
패키징 시 위 Localization 폴더를 UFS로 포함하도록 설정했습니다.
이후 추가하는 문구도 FString 대신 FText / NSLOCTEXT / StringTable을 사용하고 번역 목록에 추가하세요.
고유 이름·임시 ID·프로젝트 외부 플러그인 문구와 새로 추가되는 문구까지 자동 번역하는 기능은 아닙니다.
