# 플레이어 Shift 유지 달리기

- 비전투 중 Shift를 누른 채 이동하면 기본 이동 속도의 1.5배로 달린다.
- Shift를 놓거나 메뉴 진입·입력 취소가 발생하면 달리기를 해제한다.
- 정지 시 달리기 포즈를 재생하지 않는다. 점프·공격·스킬·경직 중에는 달리기 가속을 적용하지 않는다. 무기 전환 중에는 이동과 달리기를 유지한다.
- 남녀 맨손·검은 Sword, 활은 Archer, 스태프·완드는 Mage의 기존 리타겟 Run_Fast 루프를 사용한다.
- 루프는 애니메이션 그래프에서 원래 속도로 반복하며 일반 이동과 부드럽게 혼합한다.
- 전투 중 Shift를 새로 누르면 Dodge 행동을 요청한다. 현재 바라보는 방향을 유지하면서 입력 방향의 원본 닷지 거리를 2배속으로 이동한다. 입력이 없으면 후방으로 회피한다. 무적·회복·3초 쿨다운 세부 규칙은 Player_DirectionalCombat.ko.md를 따른다.
- 전투 진입 시 달리기 유지 상태를 해제한다. 누르고 있던 Shift로 자동 닷지가 발생하지 않으며 다시 눌러야 한다.
- 별도 SP 소모는 추가하지 않았다.

## 전투 판정

- 기본 적 AI가 살아 있는 플레이어를 추격·공격 대상으로 유지하는 동안 교전 시간을 갱신한다. 단순 근접·타겟 선택만으로는 진입하지 않는다.
- 적 대상 공격 효과 커밋과 실제 피해 적용 시에도 교전 시간을 갱신한다. 적 대상이 없는 빈 공격이나 아군 회복은 교전 시간을 갱신하지 않는다.
- 마지막 교전 갱신 후 5초가 지나면 전투가 해제된다. 적 사망·추격 포기 시에도 유예를 적용한다. 닷지 중에는 완료까지 전투 표시를 유지한다.
- 시간은 기존 PlaySecond를 사용한다. HUD에 전투 여부와 Shift 동작을 표시한다.
- 별도 BehaviorTree/StateTree를 사용하는 적은 해당 AI에서 추격 대상의 ASC `MarkCombat()`을 갱신하는 연동이 필요하다.

## 에셋 적용

에디터 빌드 후 Unreal Python으로 `Tools/Characters/setup_player_sprint.py`를 실행한다.
기존 Run_Fast 클립을 각 프로필의 Sprint에 연결하고 이전 Run_Fast 대시 몽타주 연결을 해제한다.
전투 닷지 연결은 `Tools/Characters/setup_player_combat_dodge.py`로 생성한다.
`setup_player_dash.py` 및 `review_player_dash.py`는 이전 대시용 도구이므로 현재 달리기 설정에 실행하지 않는다.

무기 전환 중 하체는 현재 보행·달리기 포즈를 계속 평가하고, 척추부터 상체에만 꺼내기·넣기 몽타주를 적용한다. IC.Input.WeaponSwitchKeepsLocomotion에서 남녀 보행·달리기의 하체 관절을 중단 없는 기준 포즈와 비교한다.

2026-11-02 확인: 해당 자동화 검사와 무기 4계열 순환·중단 검사를 통과했다.
렌더링된 PIE에서도 남녀 × 보행·달리기 × 5회 무기 순환의 20개 경우를 통과했다.
보행 450cm/s·달리기 675cm/s를 유지하면서 다리 관절이 계속 움직였고, 남녀 대표 화면을 확인했다.
결과와 화면은 Saved/MovingWeaponReview에 있다. 이동은 실제 CharacterMovement 입력 큐에 넣고 무기 전환은 컨트롤러 입력 명령으로 실행한다.
