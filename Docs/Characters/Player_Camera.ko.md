# 플레이어 카메라

- 마우스 휠 위: 확대, 아래: 축소. 기본 거리 420cm, 범위 200~650cm, 한 단계 50cm.
- Camera 카테고리의 MinimumCameraDistance, MaximumCameraDistance, CameraZoomStep으로 조절한다.
- Enhanced Input의 런타임 전용 Mapping Context와 Axis1D Input Action을 사용한다.
- 줌은 부드럽게 전환한다. 메뉴·대화·일시정지 중에는 줌과 타겟 추적 입력을 처리하지 않는다.
- Spring Arm의 기존 카메라 충돌 검사를 유지한다. 충돌 시 즉시 안전 거리로 당기고, 장애물에서 벗어나면 천천히 복귀한다.
- 명시적 NextTarget 명령으로 선택한 적만 카메라가 따라본다. 공격 시 자동으로 찾은 적은 카메라 추적을 시작하지 않는다.
- 마우스 시점 입력은 카메라 추적만 해제하며 전투 대상 선택은 유지한다. ClearTarget·적 사망·거리 초과·기존 가림 유예 초과 시 추적을 해제한다.
- 캐릭터는 기존처럼 이동 방향을 바라본다. 방향별 전투 이동 애니메이션이 아직 분리되지 않아 강제 정면 유지 이동은 추가하지 않았다.
- 1인칭·어깨 전환은 이번 작업 범위에 포함하지 않았다.

실제 플레이에서 벽·구석·타겟 이동 시 카메라 품질 확인은 아직 수행하지 않았다.
