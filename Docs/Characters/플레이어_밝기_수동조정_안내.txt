플레이어 밝기 조절 — 실제 조명과 그림자를 받는 재질

현재 남녀 플레이어 재질: /Game/IsekaiClass/Player/Materials/WorldReactive
원래 툰 색 계산 → Base Color, Emissive Color → 0, Shading Model → Default Lit.
표면이 월드의 직접광·간접광·그림자를 받도록 연결했다.

눈동자·흰자·하이라이트·아이라인·눈썹·속눈썹·입은 M_ICAuthoredFeatureLit 부모를 사용한다.
ICFeatureAlbedoTexture는 원본 diffuse 텍스처, ICFeatureAlbedoTint는 원본 색 인자다.
RGB는 Base Color, 알파는 Opacity Mask로 연결하며 Default Lit · Masked · Emissive 0이다.
남성은 눈이 포함된 머리 아틀라스 한 슬롯에 적용한다. 기존 MToon 최종 색 출력은 눈에 재사용하지 않는다.

Material Instance의 ICAlbedoScale = 0.65가 표면색 배율이다.
높이면 밝아지고 낮추면 어두워지지만 최종 화면 밝기의 퍼센트는 아니다.
주간과 야간에 공통 적용된다. 시간별 강제 배율로 실내를 어둡게 만드는 방식은 쓰지 않는다.
ColorScaleAllMat는 1로 둔다. bUseLight, bUseLightForce, bUseFilmTonemapInverse,
bDivAdaptation, MatCap, Rim은 현재 꺼져 있으므로 별도 이유 없이 켜지 않는다.

원본 텍스처·불투명도·얼굴용 노멀 보정은 유지했다. 실제 조명에 따라 앞머리 그림자가 얼굴에 생길 수 있다.
남성은 원래 아틀라스 두 슬롯을 사용하며 피부·눈만 따로 조절하는 UV 마스크는 없다.

월드는 직전 8번의 단일 태양광 구성을 유지한다. 이번 수정에서는 맵·노출·후처리·SkyLight를 추가로 바꾸지 않았다.
ToonBrightness / ICCharacterBrightness / NightBrightness / ICPartProfile은 현재 플레이어에서 사용하지 않는다.
프리셋을 바꾸면 기본 메시의 재질을 다시 사용한다.
