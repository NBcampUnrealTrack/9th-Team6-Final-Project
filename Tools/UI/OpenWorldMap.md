# L_OpenWorld 정적 지도

`STH_UI`의 `L_OpenWorld`에서 마을만 위에서 촬영한 이미지를 사용합니다.
런타임에서는 SceneCapture를 실행하지 않고, 저장된 텍스처 위에 플레이어·포탈·미니맵 마커를 표시합니다.

## 에셋과 좌표

- 이미지: `/Game/IsekaiClass/UI/Map/T_OpenWorld_Village_UI`
- 지도 설정: `/Game/IsekaiClass/UI/Map/DT_IC_LevelMap`, 행 `L_OpenWorld`
- 촬영 원본: `Content/IsekaiClass/UI/Map/Source/L_OpenWorld_DevelopedArea_TopDown.png`
- 중심: X = -56,000 cm, Y = 610,000 cm
- 정사각형 폭: 65,000 cm, 해상도: 3072 × 3072
- 이미지 오른쪽은 월드 +Y, 이미지 아래쪽은 월드 -X
- U = 0.5 + (월드 Y - 610000) / 65000
- V = 0.5 - (월드 X + 56000) / 65000

N 키는 마을 전체 지도, 최신 dev의 M 키는 워프 목적지 목록을 사용합니다. 마을 이미지는 미니맵에서 플레이어 중심으로
4배 확대하며, 기본 표시 폭은 약 162.5 m입니다. 가장자리 흐림 효과는 사용하지 않습니다. 확대 범위는 데이터테이블의 MinimumZoom /
MaximumZoom과 위젯의 MinimapZoom으로 결정합니다.

플레이어와 NPC 등의 마커, 이미지 잘라내기는 동일한 좌표식을 사용합니다.
촬영 범위를 벗어난 부분은 기본 배경만 표시하며, 이미지를 늘이거나 반복하지 않습니다.
이 이미지는 마을 중심의 650 m 범위 지도이며 L_OpenWorld 전체 랜드스케이프를 포함하지 않습니다.
섬은 촬영 범위에서 제외하며, 촬영 당시의 조명 표현은 그대로 표시됩니다.

현재 레벨 이름으로 지도 설정을 선택하므로 PIE의 `UEDPIE_*` 접두사에도 대응합니다.
별도 행이 없는 레벨은 기존 MapTable / PresentationTable 설정을 사용합니다.
기존 테스트맵 데이터와 이동 규칙, 레벨 배치는 수정하지 않습니다.
`Config/DefaultGame.ini`에는 UI/Map 디렉터리를 쿠킹 대상으로 추가했습니다.

## 맵이 바뀌었을 때

1. Unreal Editor Python으로 `Tools/UI/capture_open_world_map.py`를 실행합니다.
2. `Tools/UI/setup_open_world_map.py`로 원본을 다시 가져오고 좌표 데이터를 저장합니다.
3. `IC.UI.Map.StaticOpenWorld` 자동 검증을 실행합니다.

두 스크립트는 레벨을 저장하지 않습니다. 촬영 범위를 바꿀 때는 캡처 스크립트,
설정 스크립트 및 좌표 검증의 중심·폭을 함께 갱신해야 합니다.
검증은 PIE 레벨 이름 선택, 촬영 중심과 모서리 투영, 고도 독립성, 플레이어 중심 좌표,
배경 표시, 저장된 위젯의 가장자리 흐림 해제, 지도 경계에서의 잘라내기를 확인합니다.
렌더링 가능한 에디터로 실행하면 `Saved/OpenWorldMapReview`에 워프 목록과 미니맵 미리보기도 생성합니다.

기존 T_OpenWorld_Overview 텍스처와 구분하기 위해 마을 전용 텍스처를 별도 이름으로 가져옵니다.

## 미니맵 확대·축소

게임 플레이 중 Alt를 누른 채 마우스 휠을 위로 돌리면 확대, 아래로 돌리면 축소합니다.
한 칸당 1.25배씩 바뀌며 마을 지도는 1~8배 범위입니다. 플레이어를 중심으로 배경과 마커에 같은 배율을 적용합니다.
일반 휠은 기존 카메라/상호작용 조작에 사용됩니다. 메뉴·대화 중이거나 게임 화면이 입력을 받지 않는 동안은 미니맵 단축키를 처리하지 않습니다.

## N 마을 지도

N으로 마을 전체 지도를 엽니다. 지도 안에서 일반 휠을 위로 돌리면 커서 위치를 기준으로 확대하고, 아래로 돌리면 축소합니다(1~8배).
N / Esc / 닫기로 돌아오면 카메라 휠 조작이 복구됩니다. M은 기존 워프 목록으로 이동합니다.
지도 메뉴 상태와 커서·일시정지는 기존 UI 관리자를 사용하며, 캐릭터/카메라/컨트롤러 코드는 변경하지 않습니다.

확대한 N 지도에서 왼쪽 버튼을 누른 채 끌면 지도가 마우스를 따라 이동합니다. 지도 경계에서 이동을 제한하며 1배로 축소하면 전체 보기로 돌아옵니다. 버튼을 놓거나 지도 창을 닫으면 드래그와 마우스 캡처를 해제합니다.
