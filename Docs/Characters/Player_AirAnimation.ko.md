# 플레이어 점프·낙하·착지

## 상태 전환

지상 → 점프 시작 → 상승 루프 → 낙하 루프 → 착지 → 지상 이동.
발판에서 떨어지면 점프 시작을 건너뛰고 낙하로 진입한다.
수직 속도 0 이하에서 낙하로 전환하고, CharacterMovement의 지상 복귀로 착지를 판정한다.
짧은 바닥 접촉 변화(공중 0.08초 이하)는 착지 동작을 생략한다.
이동 중 착지는 최대 0.12초, 정지 착지는 최대 0.3초 후 지상으로 복귀한다.
점프 시작은 최대 0.2초 후 상승 루프로 연결한다. 단계 전환은 블렌딩한다.

## 에셋과 이동

- 남녀 각각 맨손·검은 Sword, 활은 Archer, 스태프·완드는 Mage의 Jump Start/Loop/Stop 또는 End 클립을 사용한다.
- 낙하는 공통 Manny MM_Fall_Loop을 각 플레이어 스켈레톤으로 리타겟팅한다. 무기별 전용 낙하 포즈는 아니다.
- 모든 클립의 루트 모션을 끄고 이동·중력·착지는 CharacterMovement가 담당한다.
- 착지 애니메이션 자체로 입력을 잠그지 않는다. 재점프·공격은 기존 입력 규칙을 따른다.
- 공격·피격·닷지는 기존 DefaultSlot을 통해 이동 애니메이션 위에서 재생한다.
- 기존 NPC 프로필은 새 필드가 없으면 기존 Jump 루프로 대체한다.
- 재생 중 텔레포트와 최초 초기화에서는 가짜 착지를 생성하지 않도록 상태를 초기화한다.

에디터 빌드 후 `Tools/Characters/setup_player_air.py`로 프로필을 저장한다.
이번 작업에서 실제 플레이 테스트는 실행하지 않았다. 낙하 시 무기 자세와 착지 블렌딩의 시각적 조정은 플레이 확인 후 필요할 수 있다.
