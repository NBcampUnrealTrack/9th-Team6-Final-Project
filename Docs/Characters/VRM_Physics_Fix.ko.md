# VRM 의상 충돌·머리카락 튐 수정 — 2026-10-23

후속 요청으로 현재 머리·옷 물리는 Kawaii Physics로 전환했다.
현재 설정은 `KawaiiPhysics_Setup.ko.md`를 참고한다. 아래는 이전 VRM 수정 이력이다.

남녀 플레이어와 R01 NPC 11명은 각 메시의 `ABP_Post_*`에서 VRM4U
SpringBone을 실행한다. 이번 수정은 기존 VRM1 물리를 보완하며, 동일 본에
다른 물리 노드를 추가하지 않는다.

## 원인과 수정

`VRM1SpringManager::init`이 흔들림 방향과 길이에 부모→현재 본의 위치
벡터를 사용하고, 꼬리의 초기 위치를 현재 본의 중심으로 설정하고 있었다.
머리카락 뿌리의 부모 방향과 실제 머리카락이 뻗는 자식 방향은 다르다.
현재 본→자식 본의 로컬 벡터와 실제 자식 끝 위치로 초기화하도록 수정했다.
자식이 없는 끝 본은 추가 회전을 계산하지 않고 부모를 따른다.

`reset`은 생성 시점의 월드 좌표인 `initialTail`을 재사용하고 이전 회전을
유지했다. 이를 비우고 다음 입력 자세에서 다시 초기화한다. 순간이동과
입상→수면 전환 후 과거 위치로 당겨지는 현상을 방지한다. 100ms를 넘는
프레임 지연에서도 현재 자세로 다시 초기화하며, 일반 적분 단계는 최대
1/60초로 나누고 감쇠를 프레임 시간에 맞춘다.

변경 전 대기 검사에서는 보조 본의 최대 프레임 간 이동이 약 229.81cm였고,
수정 후 동일한 대기 검사에서는 최대 4.22cm 미만이었다. 본의 로컬 길이는
원래부터 변하지 않았다. 잘못된 방향으로 큰 회전이 발생하면서 스키닝된
옷과 머리카락이 늘어나거나 뒤집히는 모습으로 나타났다.

의상 메타데이터 11개에서 코트·치마·소매의 비어 있던 충돌 그룹 연결
146개를 보완했다. 치마는 기존 양쪽 허벅지 그룹을, 소매는 같은 쪽 팔과
손 그룹을 사용한다. 허벅지 충돌체가 없던 플레이어 남성·R01_08·R01_09·
R01_10에는 기준 자세의 실제 다리 길이로 만든 캡슐을 양쪽에 추가했다.
기존 머리카락·가슴 본 설정과 작성된 충돌체 수치는 보존한다.

## 검증과 재실행

- `Tools/BuildProject.ps1 -Target Editor`: Editor 빌드 성공.
- `Tools/Characters/verify_assets.py`: 에셋·데이터 검사 373개 통과.
  머리·의상 충돌 연결과 본/그룹 인덱스 검사도 포함한다.
- `Tools/Characters/review_secondary_motion.py`: 13개 메시 × 30/60/120Hz ×
  대기·달리기/회전·250ms 지연·순간이동 초기화·수면 초기화·공격을 검사한다.
  본 길이와 유한 좌표, 대기 안정성, 초기화 후 입력 자세 일치를 검사한다.
- 저장한 메타데이터를 새 프로세스에서 다시 로드한 뒤 충돌 보완 도구가
  추가 변경을 요구하지 않는 것도 확인했다.
- `IC.Characters` 자동 검사 5종 통과: 공통 애니메이션 그래프, NPC 생성·
  일정·수면/기상, 보조 물리 회귀, 무기 기하, 선물 거래. 최종 보조 물리
  측정 234행에서 길이·초기화 위치 오차는 출력 정밀도 기준 0cm이며,
  초기화 회전 오차의 최댓값은 0.000002도였다.

`fix_vrm_collisions.py`는 기본적으로 변경 계획만 만든다. 모델을 다시
가져온 뒤에는 Unreal Python 환경의 `IC_APPLY_VRM_COLLISIONS=1`로 실행하면
필요한 메타데이터만 저장한다. 최초 변경 전 패키지는
`Saved/SecondaryMotionReview/OriginalAssets`에 백업한다.

`review_secondary_motion.py`는 `IC_SECONDARY_REVIEW_LABEL`로 출력 폴더를
구분한다. `IC_SECONDARY_REVIEW_CAPTURE=1`이면 렌더링 가능한 에디터에서
캡처도 저장한다. 실패 시 예외를 발생시킨다. 결과는
`Saved/SecondaryMotionReview/Final/Measurements.csv`와 PNG 39개에 있다.
자동 회귀 검사는 `IC.Characters.SecondaryMotionResetAndLengths`로 실행한다.

이번 검사는 제공된 모델과 동작의 본 물리 및 연결을 대상으로 한다.
메시 삼각형 단위의 옷 자체 충돌이나 모든 자세에서의 접촉을 증명하는
검사는 아니다. 기존 `InspectCharacterPresentation`의 유한 좌표 검사만으로
옷·머리카락의 접촉 품질을 판정하지 않는다.

이후 실제 렌더링한 PIE 39개 경우의 결과는 `Live_Play_Review.ko.md`에
기록했다. 이동 중 큰 튐은 재현되지 않았지만, NPC 수면의 침구 관통은
남아 있으며 플레이어 수면에는 누운 연출이 없다.
