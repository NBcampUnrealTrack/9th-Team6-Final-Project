# 실제 플레이 의상·머리 검수 — 2026-10-23

이 문서는 Kawaii Physics 전환 전 VRM 검수 기록이다. 후속 적용 상태는
`KawaiiPhysics_Setup.ko.md`에 기록한다. 사용자의 후속 지시에 따라 침대와
수면 모션은 이후 수정·시각 검수 범위에서 제외했다.

수정된 VRM 물리로 UE 5.8의 `L_TestMap`을 렌더링한 PIE에서 실행했다.
남녀 플레이어와 R01 NPC 11명의 걷기·달리기에서 이전의 큰 머리 튐과
늘어남은 재현되지 않았다. **수면 장면은 미통과다.** NPC의 머리·몸과
침구가 겹치며, 플레이어는 현재 실제로 누워 자는 연출이 없다.

## 실행 범위와 증거

- 남녀 플레이어 × 걷기·달리기·수면 명령: 6개 경우.
- NPC 11명 × 걷기·달리기·일정에 따른 취침: 33개 경우.
- 총 39개 경우, 각 8장, 최신 유효 캡처 312장. 앞/뒤 사선 시점으로 확인했다.
- 미리보기 메시 대신 실제 플레이어 Pawn, NPC AI, 공통 런타임 애니메이션과
  VRM post process를 사용했다. 검수 카메라만 플레이어 카메라에서 분리했다.
- 플레이어는 기본 검 장비로 이동 입력을 주었다. 실제 이동 속도는 걷기
  135cm/s, 달리기 450cm/s다. NPC는 정상 일정의 AI 이동을 사용했고,
  달리기 검수 동안만 PIE 안에서 속도 상한을 600cm/s로 높였다.
  NPC 걷기는 180cm/s, 달리기는 주로 600cm/s였다.
- NPC 취침은 시간을 20:30으로 진행한 뒤 실제로 침대에 도착하여
  `ICCharacterAnimInstance.sleeping=true`가 되는 것을 기다렸다.
  수면 캡처 88장 모두 해당 상태와 이동 속도 0을 기록했다.
- 렌더링 중 관측한 tick 간격은 약 45~125ms다. 이 세션은 고정
  30/60/120fps 검사가 아니며, 별도의 기존 수치 회귀 검사와 구분한다.
- 검수 저장은 `IC_Visual_<GUID>` 접두사를 사용했다. 종료 후 PIE는 중지했다.

캡처와 측정: `Saved/LiveCharacterReview/`.
`samples.json`은 재촬영 이력도 포함하므로 같은 `(case, frame)`의 마지막
기록을 사용한다. 최초 임시 이름 `PLAYER_M_Walk`는 제외한다.
`ReviewSheets/`에는 대상별 걷기·달리기·수면 비교 이미지와
`SleepFront.jpg`, `SleepBack.jpg`가 있다.

## 남은 문제의 코드 근거

`AICCharacterBase::UpdatePresentationTransform`은 프로필의
`SleepMeshTransform`을 침대 앵커에 곱해 메시 전체를 배치한다.
기존 보정은 머리의 XY와 골반 높이를 기준으로 하며, 베개·머리·머리카락의
실제 표면 접촉까지 맞추는 계산은 아니다. 실제 화면상 수면 위치를 다시
보정해야 한다.

`AICNPCTestLayout::BeginPlay`의 검사 침대는 일정 이동을 막지 않도록
`NoCollision`이다. 현재 VRM1 solver의 충돌도 모델 내부 본에 붙은
메타데이터 충돌체를 처리한다. 따라서 기존 몸 충돌 그룹 연결을 고친
것만으로 베개나 매트리스와의 접촉까지 해결되지는 않는다.
수면 배치와 침구에 대한 보조 물리 접촉을 별도로 다뤄야 한다.

플레이어의 `AICPlayerController::Sleep`은 회복과 시간 진행을 즉시
처리한다. 공통 애니메이션의 취침 판정은 NPC 일정 분기에 있으므로
플레이어의 누운 수면 모습은 현재 게임플레이에서 제공되지 않는다.
단순히 Kawaii Physics 설정을 추가하는 것으로 해결할 문제는 아니다.

이번 결과는 이 테스트 맵과 장비 조합의 짧은 실제 플레이 검수다.
모든 의상 삼각형의 무관통, 모든 장비/애니메이션 조합, 경사·전투·장시간
플레이 또는 패키지 실행까지 통과했다는 의미는 아니다.

## 재현

에디터 콘솔에서 `py <프로젝트 절대 경로>/Tools/Characters/live_character_review.py`를
실행한다. 시작 옵션은 `-ExecCmds="py <스크립트 절대 경로>"`를 사용할 수 있다.
비동기 PIE를 유지해야 하므로 자동 종료하는 `-ExecutePythonScript`는 쓰지 않는다.
다른 사용자의 진행 중인 PIE에서는 실행하지 않는다.

`Saved/LiveCharacterReview/control.json`에 다음과 같이 기록하고
`status.json`이 같은 id의 `captured`가 되는 것을 기다린다.

```json
{"id":"NPC_R01_002_sleep","mode":"npc_sleep","npc":"NPC_R01_002"}
```

지원 mode는 `player_walk`, `player_run`, `player_sleep`, `npc_walk`,
`npc_run`, `npc_sleep`이다. 플레이어 `preset`은 남성 0, 여성 1이다.
플레이어 수면은 실제 수면 명령의 결과를 기록하며 누운 자세를 강제하지 않는다.
같은 경우를 다시 촬영하려면 `retake` 등의 값을 바꾼다.
종료는 `{"mode":"stop"}`을 기록한 뒤 PIE를 중지한다.
스크립트를 재실행할 때도 먼저 이전 capture loop를 stop해야 한다.
