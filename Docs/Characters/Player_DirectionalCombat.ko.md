# 방향별 전투 이동·닷지

## 조작

- 비전투: 기존 이동 방향 회전 및 Shift 유지 달리기.
- 전투: 선택한 적을 바라보며 이동. 대상이 없으면 카메라의 수평 방향을 바라본다.
- 이동 입력은 카메라 기준이며, 캐릭터 기준 실제 속도로 앞·뒤·좌·우·대각선 8방향 애니메이션을 혼합한다.
- 전투 중 Shift: 현재 이동 입력 방향으로 닷지. 입력이 없으면 캐릭터 뒤로 닷지한다.
- 닷지 중 바라보는 방향을 유지한다. 실제 이동은 입력 방향 그대로, 애니메이션은 가장 가까운 45도 방향을 선택한다.
- 전투 진입 시 기존 시야·거리 조건으로 대상을 한 번 선택한다. 대상 해제 후 매 프레임 다시 강제로 선택하지 않는다.

## 구현

- 애니메이션 프로필에 CombatLocomotion과 DirectionalDodges를 추가했다.
- 남녀 플레이어에 검·활·마법 팩별 2차원 Blend Space와 8방향 닷지 몽타주를 연결한다. 맨손은 검 팩, 지팡이와 완드는 마법 팩을 공유한다.
- 방향 배열: 앞, 오른쪽 앞, 오른쪽, 오른쪽 뒤, 뒤, 왼쪽 뒤, 왼쪽, 왼쪽 앞.
- 이동 입력 의도는 공격 중에도 기록하고, 입력 해제 및 메뉴 전환 시 비운다.
- 기존 회피 거리·시간·무적·쿨다운 및 입력 버퍼 정책을 사용한다.
- 애니메이션은 In-place로 사용하며 실제 닷지 이동과 충돌 처리는 기존 GAS 동작이 담당한다.
- 에셋 생성: Tools/Characters/setup_player_directional.py. 기존 기본 에셋 및 무기 전환 생성기는 새 프로필 필드를 보존한다.

## 확인 범위

실제 플레이 테스트는 수행하지 않았다. 적 주위를 도는 이동, 8방향 닷지, 무입력 후방 닷지, 전투 해제 후 달리기 전환의 시각적 자연스러움은 에디터 플레이에서 확인이 필요하다.
