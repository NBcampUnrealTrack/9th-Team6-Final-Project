# 플레이어 전투 입력 제한

## 현재 기본 규칙

| 상태 | 이동 | 점프 |
| --- | --- | --- |
| 일반 | 허용 | 허용 |
| 피격 경직·사망·귀환 | 차단 | 차단 |
| 닷지 | 밀어내기 중 차단, 이동 완료 후 마지막 회복 구간에서 일반 이동 재개 | 차단 |
| 공격 | 제자리 공격 | 차단 |
| 스킬: bCancelOnUserMovement=true | 실제 이동 입력으로 스킬 취소 후 이동 | 차단 |
| 스킬: bCancelOnUserMovement=false | 시전·회복 종료까지 차단 | 차단 |
| 무기 전환 | 보행·달리기 유지, 하체 이동 포즈와 상체 전환 동작 혼합 | 차단 |
| 메뉴·대화 | 기존 게임 입력 차단과 입력 초기화 사용 | 차단 |

이동 제한은 ASC의 `CanAcceptMovementInput`, 이동 취소 처리는 `HandleMovementInput`,
점프 허용은 `CanAcceptJumpInput`으로 판단한다.
플레이어 컨트롤러는 제한 중 대기 중인 이동 입력과 수평 속도를 지워 관성 이동도 막는다.
공중에서는 수직 속도를 유지하므로 경직으로 중력이 정지하지 않는다.
메뉴 전환 시 점프·달리기 유지 상태와 잔여 이동 입력을 정리한다.
메인 메뉴·설정·인벤토리·NPC 대화와 서비스 창에서는 마우스를 표시하며 클릭해도 숨기거나 캡처하지 않는다. 실제 게임 조작 화면으로 돌아오면 커서를 숨기고 카메라 입력을 캡처한다. NPC 대화의 시간 정지 규칙은 커서 표시 여부와 독립적이다.

공격·닷지 요청의 경직 제한, 공격 버퍼, 공격 취소 구간과 스킬별 닷지 취소 규칙은 기존 GAS 처리를 따른다.
공격별 이동 속도 설정과 회피 후 입력 버퍼 확장은 이번 범위에 포함하지 않았다.

무기 전환·닷지·커서 변경은 에디터 빌드와 관련 자동화 검사로 확인한다. 렌더링 검토 도구는 Tools/Characters/review_moving_weapon_switch.py와 review_player_dodge.py다.
