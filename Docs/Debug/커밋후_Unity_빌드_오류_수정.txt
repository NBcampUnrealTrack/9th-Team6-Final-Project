2026-10-28 / Leader / 커밋 후 Unity 빌드 오류 수정 완료

원인
- 커밋 전에는 수정/미추적 C++ 파일을 Adaptive Unity가 개별 컴파일했다.
- 커밋 후 작업 트리가 깨끗해지면 같은 파일들이 Unity 묶음에 들어간다.
- ICLocalization.cpp의 익명 네임스페이스 Loaded/Cache 변수가 같은 묶음의
  ICDefinitionLibrary 및 엔진 MovieScene 헤더의 지역 변수와 충돌하여 C4459 발생.
- ICEnhancementWidget의 Add(기본 bool 인수)와 ICPartyMenuWidget의
  Add(기본 float 인수)가 같은 묶음에서 후보가 되어 C2668 발생.
- 설정 헤더를 먼저 넣은 UI 소스 12개의 첫 헤더 순서 진단도 정리.

수정
- 번역 캐시/상태를 전용 ICLocalizationState 네임스페이스로 격리.
- 강화 화면 레이아웃의 Add 호출을 ICEnhanceLayout::Add로 명시.
- UI 소스는 자신의 헤더를 첫 번째로 포함하도록 정리.
- Tools/BuildProject.ps1에 -FullUnity 선택 옵션 추가.
  내부적으로 -DisableAdaptiveUnity를 전달해 수정된 파일도 Unity 묶음에 포함한다.
  기본 빌드 설정은 기존대로 유지.
