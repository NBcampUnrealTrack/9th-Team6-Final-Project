# 게임패드 공통 입력

## 지원 범위

- Xbox: Windows에서 표준 게임패드로 인식되는 입력을 사용합니다.
- DualShock / DualSense: PC에서는 Steam Input으로 표준 게임패드 입력으로 변환하는 구성을 대상으로 합니다. Steam에 게임 실행 파일을 추가하고 PlayStation 컨트롤러용 Steam Input을 활성화한 뒤 Steam에서 실행합니다.
- 플스 패드의 USB/블루투스 직접 입력, PS 콘솔 빌드, 햅틱/적응형 트리거 지원을 의미하지 않습니다.
- 실제 패드 확인 및 빌드는 수행하지 않았습니다. 메뉴 전체의 포커스 이동·확인·취소와 기기별 버튼 아이콘은 별도 작업입니다. 캐릭터 생성 및 메뉴 조작에는 키보드/마우스가 필요할 수 있습니다.

## 플레이 중 매핑

| 기능 | Xbox | PlayStation |
|---|---|---|
| 이동 | 왼쪽 스틱 | 왼쪽 스틱 |
| 카메라 | 오른쪽 스틱 | 오른쪽 스틱 |
| 점프 | A | ✕ |
| 달리기 유지 / 전투 닷지 | B | ○ |
| 상호작용 | X | □ |
| 무기 전환 | Y | △ |
| 일반 공격 | RT | R2 |
| 현재 무기 스킬 | RB | R1 |
| 타깃 전환 | 오른쪽 스틱 클릭 | R3 |
| 퀵슬롯 1~4 | 방향키 위·오른쪽·아래·왼쪽 | 동일 |
| 메뉴 열기 | Menu | Options |
| 퀘스트 | View | Share/Create에 대응하는 표준 입력 |

현재 dev는 방어 입력을 비활성화하므로 LT/L2는 미할당입니다. Steam Input에서 일반 게임패드 레이아웃을 사용해야 하며 키보드 에뮬레이션 레이아웃은 위 표와 다를 수 있습니다.

## 구현

`IMC_Gamepad` 에셋에 기존 Input Action과 공통 게임패드 키, 스틱 Modifier를 저장합니다. 콘텐츠 브라우저의 `IsekaiClass/Input/Contexts/IMC_Gamepad`에서 수정할 수 있습니다. `AICPlayerController::GamepadMappingContext`가 에셋을 참조하며, `ApplyInputMapping`에서 키보드 컨텍스트와 함께 등록하고 제거 시 함께 해제합니다. 키보드 리바인딩은 별도 `IMC_Gameplay` 복사본을 사용합니다. `Tools/Input/setup_gamepad_input.py`는 초기 매핑 재생성용이며 재실행하면 에셋의 수동 편집을 덮어씁니다.

스틱에는 반경 데드존 0.2를 적용하고, 오른쪽 스틱은 초당 가로 120도·세로 90도를 기준으로 프레임 시간 및 기존 카메라 감도/반전 설정을 적용합니다. 왼쪽 스틱 강도는 이동 입력에 전달됩니다. 달리기·닷지 및 입력 제한은 기존 행동 처리기를 공유합니다.
