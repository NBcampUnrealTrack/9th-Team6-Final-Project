# 생활 DT 변경 검증 기록

## 2026-10-29 씨앗 상점 회귀 검사

`IC.Life.Expansion.AtomicSeedCart`의 예전 씨앗 5개 고정 검사를 제거했다. 현재 서비스 DT가 참조하는 상점 DT의 항목 수와 아이템 ID를 읽어 판매 목록을 검증한다. 현재 DT는 6종이며, 여러 씨앗의 원자적 구매·판매와 실패 시 변경 방지 검사도 통과했다.

## 2026-10-27 생활 기능 검증

검증일: 2026-10-27. `IsekaiClassEditor Win64 Development` 빌드 성공.

## 완료한 검증

- 자동화 `IC.Life` 6개 통과: 달력 기준 채집 재생, 작물 단계·수확·재생·저장, 닭 피해·처치·보상·중복 방지·가방 초과, 아이템 회복·씨앗 상점 가격·저장 호환, 제작대 UI 흐름, 채집 게이지.
- 확률 검증은 128개의 서로 다른 처치 식별자로 수행. 닭고기 보장, 달걀 미지급과 지급, 지급 수량 1~4 모두 확인.
- 기존 기능 회귀 검사 82개 중 최종적으로 81개 통과. 최초 헤드리스 실행에서 화면을 요구한 항목은 렌더링을 켜고 재검증했다. 두 회귀 테스트의 예전 재료 입력·퀘스트 아이템 검사 컨테이너도 수정 후 통과.
- 미해결 1개: `IC.UI.SaveSessionInteraction`의 `Gameplay projection shares the common UI content rect` 검사. 렌더링 재검증에서도 이 사각형 일치 검사가 실패했다. 이번 생활 구현의 통과 항목과 구분하여 기록하며, 전체 테스트가 모두 통과했다고 보고하지 않는다.

## 실제 플레이

`Saved/LifeCalendarLiveReview/Review.json`: 완료.

- 첫 메시에서 자연 성장, 조기 수확 불가.
- 하루 후 다음 메시, 원본 최종 메시에서 수확 가능.
- 수확 후 게임시간 119분 동안 숨김, 120분에 첫 단계로 재생.
- 실제 5초 채집 후 게임시간 2시간 재생.
- 일반공격으로 닭 처치, 닭고기 1개 획득. 이 플레이에서는 달걀 2개 획득.
- 첫 단계·하루 후·최종 단계·수확 후·재생 후·닭 보상 화면 기록. 첫 단계와 최종 단계의 캡처를 시각적으로 확인.

`Saved/CraftingStationLiveReview/Review.json`: 완료.

- 실제 제작대와 주방에 F로 접근, W/S 목록 선택, 상세 취소, 진행 게이지, 닫았다가 같은 작업 재개.
- 새 재료로 초보자 치유완드 제작, 기존 획득 알림 `+ 초보자 치유완드 1개 획득` 확인.
- 밀로 빵 조리, `+ 빵 1개 획득` 확인.

검토 저장 공간은 기존 리뷰 도구의 분리된 네임스페이스를 사용했다. 임시 시각 검증 액터는 맵에 저장하지 않았다.
