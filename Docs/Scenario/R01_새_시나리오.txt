이세계클래스 R01 새 시나리오
작성일 : 2026-10-27
문서 상태 : 검토용 원고. 게임 코드·DT·맵에 적용하지 않음.
기준 : 첨부 원고의 55개 의뢰, 현재 퀘스트·대화·생활 시스템과 아이템 DT.

작품의 전제
Player는 이세계에서 3년을 보냈다. 최근 넘어온 R01_09, R01_10, R01_11과 마을에서 다시 만난다.
친구들의 생활을 돕는 과정에서 마을 사람들과 가까워지고, Y의 행방을 찾기 위해 영주성으로 향한다.
등장인물의 발화자는 Player와 R01_01~R01_11로 표기한다. 제공 NPC 칸에는 식별자만 적는다.
같은 퀘스트에 여러 NPC가 등장해도 대화는 각각의 장소에서 Player와 상대 한 명 사이에 이루어진다.

원고를 읽는 방법
- 퀘스트 번호는 이 문서의 번호다. 기존 게임의 퀘스트 ID나 진행 상태를 뜻하지 않는다.
- 괄호 안의 ITM/EQP/RCP/MON 식별자는 현재 DT에 등록된 참조다.
- '미등록 제안'으로 표시한 ANC/ITM 식별자는 이 문서에서만 제안하며, 실제 에셋을 만들지 않았다.
- 전달은 필요한 개수만 차감한다. '보유 확인'은 차감하지 않는다. 창고의 물품은 목표 보유량에 포함하지 않는다.
- 전투·제작 같은 누적 목표는 해당 의뢰를 시작한 뒤의 기록이다. 다른 의뢰로 전환하면 기존 시스템의 진행 규칙을 따른다.
- 퀘스트 납품은 일반 선물하기와 별개다. 선물 호감도와 퀘스트 호감도를 중복 지급하는 연출은 넣지 않는다.
- 후반 선택 의뢰는 라운드마다 한 명만 돕는다. 수락 확정 전 선택 안내가 필요하며, 수락 후 포기는 허용하지 않는 기획이다.

경쟁 의뢰 공통 규칙

1라운드 26~29 / 2라운드 30~33 / 3라운드 34~37 / 4라운드 38~41 / 5라운드 42~45.

R01_08의 위치 이동·일정 변경·동행·식사 승낙은 자동으로 실행하지 않는다. 준비가 끝난 NPC가 직접 물어보겠다는 대사로 마무리한다.
현재 조건 구조로 설계 가능한 수락 제한 방법은 문서 뒤의 연결 참고에 정리한다. 이 원고에서는 DT를 생성하지 않는다.

20개의 경쟁 원고 중 실제 한 회차에 완료하는 의뢰는 5개다. 다른 세 인물의 의뢰는 실패·완료가 아니라 수락 불가 상태다.
의뢰 수락과 실제 시작은 구분한다. 현재 시스템에서는 한 번에 하나의 의뢰를 시작 상태로 두고 누적 목표를 기록한다.
마지막 퀘스트 전에 남은 선택 의뢰를 정리할 수 있도록 둔다. 경계 진입 이전에 임의로 NPC를 철수시키지 않는다.

검토용 부록 2. 현재 시스템과 연결하는 방법

퀘스트 식별자 제안
이 문서의 01~55에 QST_SCN_R01_001~QST_SCN_R01_055를 대응시킬 수 있다. 모두 미등록 제안이다.
기존 QST_RING_001이나 테스트 퀘스트 ID를 덮어쓰지 않는다.
보상과 대화도 별도 초안 ID를 부여해야 한다. 이 문서 자체는 임포트 파일이 아니다.

기본 목표
- Talk: 대상 NPC와 전용 대화 종료를 연결. 시작 대화만으로 목표가 충족되지 않도록 DialogueID를 구분한다.
- DeliverItem: 실제 아이템 ID와 필요한 수량 지정. 보고에서 전부 충족했는지 확인한 뒤 차감·완료·보상을 함께 처리하는 기존 규칙을 사용한다.
- PossessItem: 검을 보여주는 24·43번에 사용. 가방·장비·무기 슬롯은 확인하고 창고는 제외한다. 검을 회수하지 않는다.
- Stat: 10번의 CON 조건에 사용. 기본 능력치를 기준으로 하며 HP 수치나 장비 보정치와 혼동하지 않는다.
- Defeat: 실제 MON 식별자를 각각 지정한다. '아무 R01 몬스터'라는 가상의 대상 ID를 만들어 집계하지 않는다.
- Visit: 표지판·숲 가장자리·옛집·경계에 Player 방문 앵커를 저작하는 방식. 현재 별도의 Inspect 목표 유형은 없다.
- Craft: 현재 제작 성공 이벤트는 지원하지만 이번 본문은 음식 납품 위주다. 이미 가진 음식도 납품할 수 있으며, 반드시 직접 만들었다고 단정하지 않는다.

라운드별 배타 선택
현재 FICCondition은 QuestAccepted와 QuestCompleted 조건을 평가할 수 있다. 별도 분기 시스템을 구현했다고 가정하지 않고 이 조건을 사용하는 DT 기획이다.
각 선택 의뢰는 IsAutoAccept=False, bAllowAbandon=False, bRepeatable=False를 제안한다.
같은 라운드의 다른 세 의뢰에 대해 QuestAccepted=0, QuestCompleted=0을 모두 확인하는 All 조건 그룹을 둔다.
2~5라운드는 직전 라운드 네 의뢰의 QuestCompleted>=1 중 하나를 만족하는 Any 조건 그룹도 둔다.
AcceptanceConditions의 각 그룹은 모두 통과해야 하므로 '직전 라운드 Any'와 '같은 라운드 제외 All'을 별개 그룹으로 둔다.
46번도 42~45의 QuestCompleted 중 하나를 만족하는 Any 조건 그룹을 사용한다.
PrerequisiteQuestIDs에 직전 라운드 네 의뢰를 전부 넣으면 All 조건이 되어 막히므로 그렇게 작성하지 않는다.
다음 라운드의 네 의뢰를 동시에 자동 수락하지 않는다. 선택한 의뢰 하나만 수락한 상태가 되도록 한다.
수락 제한과 포기 금지는 기획상 되돌릴 수 없는 선택이므로 수락 전 안내 문구를 명확히 적어 둔다. 안내 UI의 추가 저작은 실제 적용 단계에서 별도로 검토한다.

시간·수량·공급
채집과 채광은 게임시간 120분 뒤 재생된다. 작물은 첫 메시부터 시작해 단계마다 1440분씩 성장하고 최종 단계에서 수확한다.
밀은 5단계이므로 처음 생성된 뒤 최종 단계까지 4일이 필요하다. 수확 후 2시간 대기와 다시 성장하는 시간은 별개다.
초반의 밀 의뢰는 선택 의뢰로 두었고, 메인의 초기 납품은 반복 채집 가능한 버섯을 사용한다.
우유 획득·실제 낚시 성공·달걀 필수 납품은 메인 진행 조건에서 제외했다.
현재 닭은 고기 1개를 보장하지만 달걀은 50% 확률 1~4개이며 자동 재생 기본값은 0이다. 그 물량을 무한 공급으로 가정하지 않는다.
일반 몬스터와 지역 보스의 현재 테스트 DT 재생은 플레이시간 기준이다. 게임시간을 건너뛰는 잠자기로 몬스터가 즉시 재생된다고 안내하지 않는다.
보스 처치는 이번 위협을 막아냈다는 이야기이며, 현재 테스트맵의 보스 재생을 영구 삭제하는 처리가 아니다.
호감도 보상은 기존 상한 500을 따른다. 이미 상한이면 원고에 적힌 증가량 전부가 실제로 더해지는 것은 아니다.

검토용 부록 3. 아직 없는 장소와 소품

다음은 이 텍스트 안에서만 제안한 식별자다. 코드·DT·맵에는 추가하지 않았다.
- ANC_SCN_R01_SIGNPOST: 마을 길목 표지판 앞 방문 지점. 11·25·48번이 재사용하되 각 의뢰 시작 이후 방문을 확인.
- ANC_SCN_R01_FOREST_EDGE: 46번의 숲 가장자리 방문 지점.
- ANC_SCN_R01_OLD_HOUSE: 52번의 서쪽 옛집 방문 지점.
- ANC_SCN_R01_OLD_DRAWER: 53번의 서랍·현장 회수 위치.
- ANC_SCN_R01_R02_BORDER: 55번의 R01 측 영주성 방향 경계 방문 지점.
- ITM_QST_R01_OLD_BOX: 52번 전용 낡은 상자, Quest 탭, 전달 수량 1.
- ITM_QST_R01_FADED_NECKLACE: 53번 전용 빛바랜 목걸이, Quest 탭, 전달 수량 1.

상자와 목걸이는 기존 퀘스트 반지 ITM_QST_001을 이름만 바꿔 재사용하지 않는다. 반지의 기존 의뢰와 사용처를 보존한다.
두 전용 소품은 판매·선물·버리기를 금지하고, 현장 회수 이전에 지급하지 않는다.
현재 Quest/Loot 상호작용은 아이템을 줄 수 있지만, 스토리 소품의 출현 조건·저장 후 중복 회수 방지·기존 완료 여부에 따른 숨김은 실제 저작 단계에서 따로 검증해야 한다.
목표를 시작한 뒤 방문과 회수를 확인하고, 완료 보고에서 해당 소품을 차감한다. 이 텍스트가 그 처리를 이미 구현했다는 의미는 아니다.
스마트폰 도입 장면과 R02 후속 콘텐츠 역시 현재 원고의 연결 지점이며 새로 구현하지 않았다.

검토용 부록 4. 원문에서 바로잡은 부분

- 04번은 300골드를 퀘스트 보상에 음수로 적는 방식을 사용하지 않는다. 재료 납품과 친구들의 일손으로 밀린 숙박비를 정리하는 이야기로 바꿨다.
- 05번의 우유는 현재 확보 경로가 연결되어 있지 않아 기존 빵으로 바꿨다.
- 09·22·23번은 없는 조사 기능 대신 개별 대화로 확인한다. 11·25·46·48번의 현장 확인은 Visit 목표로 정리했다.
- 10번의 초반 CON 30 조건은 기본 능력치 1에서 지나치게 높았다. CON 2 또는 전투 연습이라는 선택 조건으로 바꾸고, 06번 보상으로 관련 엘릭서 1개를 제공하는 기획을 넣었다.
- 음식 이름, 결과 수량, 검 제작 재료는 정리된 현재 DT와 맞췄다. 삭제한 목재·밀가루·철 주괴·테스트 선물·임시 아이템을 요구하지 않는다.
- 현재 확보가 제한된 달걀·닭고기와 미연결 낚시 재료를 경쟁 의뢰의 필수 재료에서 제외했다. 해당 요리 자체는 게임에서 삭제하거나 변경하지 않았다.
- 43번은 검을 소비하지 않으면서 선물했다고 말하던 모순을 점검 의뢰로 바꿨다.
- 5라운드는 아직 보스를 발견하기 전이다. 출정 준비를 확정하기보다 숲길 점검을 앞둔 마음을 전하는 의뢰로 정리했다.
- 50번의 보스는 현재 등록된 MON_R01_BOSS_001로 명시했다.
- 52번까지는 상자와 옛집만 다룬다. 과거의 상대와 그 죽음은 53번 완료 대화에서 처음 공개한다.
- 54번은 R01_10 한 명과만 대화한다. 55번은 Player 혼자 경계에 진입하며 세 친구의 동행을 요구하지 않는다.
- 이름과 대사 번역을 준비할 때는 이 문서의 ID를 유지하고, 예를 들어 SCN.R01.Q001.Title / SCN.R01.Q001.Description / SCN.R01.Q001.Complete.001 같은 별도 문자열 키를 사용할 수 있다. 실제 스트링 테이블은 생성하지 않았다.
