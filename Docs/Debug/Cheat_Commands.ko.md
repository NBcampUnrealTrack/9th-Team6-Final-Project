# 개발용 치트 명령

PIE에서 플레이어를 만든 뒤 콘솔을 열고 입력합니다. `UICDebugCheatManager`에 등록된 Exec 명령입니다.

전체 19종의 용도와 입력 예시는 [치트_명령어_정리.txt](치트_명령어_정리.txt)에 정리했습니다.

| 명령 | 동작 |
|---|---|
| `ICGiveStarterWeapons` | 초보자 검·활·마법스태프·치유완드를 각 1개씩 가방에 지급 |
| `ICEquipStarterWeapons` | 초보 무기 4종을 지급하고 각 무기 슬롯에 장착 |
| `ICRecruitTestParty` | R01_01·02·03의 호감도를 300으로 설정하고 파티에 즉시 편성 |
| `ICGiveGold` | 현재 보유 골드에 10,000G 추가 |
| `ICAddGameHours 2` | 게임시간 2시간 경과. 채집·수확 후 재생 확인에 사용 |
| `ICAddGameHours 24` | 게임시간 하루 경과. 작물의 다음 성장 단계 확인에 사용 |
| `ICAddGameHours 0.5` | 게임시간 30분 경과 |

무기는 가방에 4칸이 필요합니다. 공간이 부족하면 전부 지급하지 않고 안내합니다. 성공하면 기존 획득 알림을 표시합니다.

시간 변경은 기존 게임 달력의 점프 경로를 사용하므로 작물 성장·채집 재생·NPC 일정에도 반영됩니다. 플레이시간 기준의 제작 게이지·몬스터 재생·전투 쿨다운은 이 명령으로 건너뛰지 않습니다.

기존 `ICAddGameMinutes`와 `ICGiveItem <ItemID> <수량>`도 계속 사용할 수 있습니다. 치트 동작은 개발 빌드에서만 활성화됩니다.
