지도 · 포탈 · 창고 뚜껑 변경 안내

지도 이미지는 AI 생성물을 사용하지 않습니다.
실제 L_TestMap을 수직 정사영 카메라로 촬영하여 Texture2D로 저장합니다.
실행 중에는 이 이미지 위에 현재 플레이어 방향과 포탈 좌표만 갱신합니다.

[사용]
M / Xbox View 또는 HUD 지도 클릭: 지도 열기. M / View / ESC / Xbox B: 닫기.
실제 포탈 가까이에서 F / Xbox X를 눌러도 지도를 엽니다.
포탈 표시를 클릭하면 500G를 내고 파티 전체가 이동합니다.
방향키 / Xbox 십자키로 포탈 선택, Enter / Xbox A로도 이동할 수 있습니다.
이동 중에는 로딩 화면을 표시하고 중복 입력을 막습니다.
골드가 부족하거나 도착 위치가 준비되지 않으면 비용을 지불하지 않습니다.

[배치]
팀원이 만든 /Game/IsekaiClass/World/Blueprints/BP_ICWarpStone을 그대로 사용합니다.
왼쪽: WRP_TEST_01 / 월드 Y=-17500
중앙: WRP_TEST_02 / 월드 Y=1000
오른쪽: WRP_TEST_03 / 월드 Y=19500
위에서 촬영한 지도에서 월드 +Y가 오른쪽, 월드 -X가 아래 방향입니다.
도착 위치는 포탈 옆 X=-250, Z=96입니다. 동료들은 주변의 안전한 바닥에 배치됩니다.

[DT]
/Game/IsekaiClass/Data/DataTable/Settings/DT_IC_MapPresentation : Default
- TravelCostGold: 이동 비용. 기본 500.
- LoadingSeconds: 최소 이동 연출 시간. 기본 1.2초.
- bUnlockPlacedPortals: 기본 True. 테스트맵의 배치된 포탈을 자동 활성화합니다.
  False이면 팀원의 기존 워프 방문/해금 기능으로 활성화해야 합니다.
- MapID: 사용할 DT_IC_Map 행.

/Game/IsekaiClass/Data/DataTable/World/DT_IC_Map : MAP_TEST_001
- Layers[0].MapTexture: 실제 캡처 이미지.
- WorldOriginCm / WorldAxisU / WorldAxisV / WorldCmPerUV: 월드 좌표 → 지도 UV 변환.
- 현재 캡처 범위: 중심 (0,1000), 가로 42000cm, 세로 21000cm.
- 이미지 2048×1024. 포탈 위치와 플레이어 위치는 동일한 변환을 사용합니다.

/Game/IsekaiClass/Data/DataTable/World/DT_IC_Warp
- 각 포탈의 VisitAnchorID / ArrivalAnchorID / VisitRadiusCm.
실제 배치된 ICWorldAnchor의 AnchorID와 일치해야 합니다.
DT_IC_Anchor의 WorldTransform과 실제 맵의 앵커 위치도 함께 맞추세요.

[UI / 캡처]
/Game/IsekaiClass/UI/Widget/WBP_IC_Map : 전체 지도.
/Game/IsekaiClass/UI/Widget/WBP_IC_Minimap : HUD 전체맵 축소 지도.
/Game/IsekaiClass/UI/Map/T_TestMap_Overview : 실제 캡처 텍스처.
맵 외형 변경 후 Tools/Life/capture_map_and_review.py를 실행하면 다시 촬영하고 이동 동작을 검증합니다.
해당 스크립트의 검증은 격리된 IC_Visual 세이브로 진행합니다.
포탈/DT/WBP 초기 저작은 Tools/Life/setup_map_travel.py.
변경 전 자산 백업은 Saved/MapTravel/Before.

[창고]
개인 창고 및 NPC 창고의 ChestPresentation.OpenRotation을 Roll=-105로 통일했습니다.
원본 BP와 테스트맵 인스턴스의 +105 덮어쓰기를 수정했습니다.
뚜껑은 위로 열리고, 창고 화면을 닫으면 원래 위치로 돌아옵니다.
