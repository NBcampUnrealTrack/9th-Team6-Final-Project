# 뽑기 기계와 바닥 드롭

## 테스트 위치

`/Game/IsekaiClass/World/L_TestMap`에서 주방 왼쪽 `(1400, -3550, 75)`에 기본 큐브 뽑기 기계를 배치했습니다.
접근하면 실제 DT 가격이 표시되며 F를 누르면 1회 뽑습니다. 기본 가격은 1,000G입니다.

블루프린트: `/Game/IsekaiClass/Life/Gacha/BP_IC_GachaMachine`.
부모 C++ 클래스: `AICGachaMachine`. 배치 액터의 `GachaMachineID`로 사용할 DT 행을 선택합니다.

## 뽑기 DT

`/Game/IsekaiClass/Data/DataTable/Life/DT_IC_GachaMachine`의 `GAC_R01_BASIC_001` 행을 수정합니다.

| 필드 | 설정 |
|---|---|
| `CostGold` | 1회 비용. 기본 1000 |
| `Pools` | 먼저 추첨할 아이템 그룹 목록 |
| `Pools[].PoolID` | 그룹을 구분하는 식별자 |
| `Pools[].NameKey` | 그룹 이름의 스트링 테이블 키 |
| `Pools[].Weight` | 그룹의 상대 확률. 0이면 해당 그룹 제외 |
| `Pools[].Items` | 해당 그룹에서 추첨할 아이템 목록 |
| `Items[].ItemID` | 실제 아이템 DT에 있는 ID |
| `Items[].Weight` | 그룹 안에서 해당 아이템의 상대 확률. 0이면 제외 |
| `Items[].MinimumCount`, `MaximumCount` | 당첨 수량의 최소·최대 |

기본 그룹은 다음과 같습니다. 1회 뽑을 때 그룹 하나와 그 안의 아이템 하나를 고릅니다.

- `GATHERING`: Weight 50. 들꽃 줄기부터 흰꽃까지 채집물 10종. 각 아이템 Weight 1, 수량 1개.
- `GROWTH_BOOK`: Weight 50. 근력·민첩·지력·체력·운의 초급/중급/고급 성장서 15종. 각 아이템 Weight 1, 수량 1개.

그룹 확률은 `그룹 Weight / 전체 그룹 Weight 합`입니다. 아이템 수가 10종과 15종이어도 그룹은 각각 50%입니다.
그룹 안에서는 각 Weight를 다시 합산합니다. 기본 성장서의 속성은 다섯 종류가 동일 확률이며, 초·중·고급도 동일 확률입니다.
예를 들어 채집물 80%, 성장서 20%를 원하면 두 그룹 Weight를 80/20으로 바꾸세요. 고급 책을 덜 나오게 하려면 그 책들의 아이템 Weight만 낮추면 됩니다.
개별 아이템의 최종 확률은 `그룹 확률 × 그룹 내부 아이템 확률`입니다. 기본 채집물은 종당 5%, 성장서는 종당 약 3.333%입니다.

골드 차감과 보상 반영은 하나의 거래로 처리합니다. 골드 부족이나 잘못된 확률 설정이면 차감하지 않습니다.
가방이 꽉 차도 정상 추첨하며, 넘친 수량은 기계 앞의 바닥 드롭으로 남고 안내 문구를 표시합니다. 가방에 실제 들어온 수량만 기존 획득 알림으로 표시합니다.

## 기본 큐브와 외형 편집

현재 아이템 97종의 바닥 드롭은 모두 엔진 기본 큐브, 크기 `(0.25, 0.25, 0.25)`로 지정했습니다. 넘친 전리품과 뽑기 결과 모두 같은 `AICDroppedItem`을 사용합니다.

나중에 `/Game/IsekaiClass/Data/DataTable/Items/DT_IC_Item`에서 해당 아이템을 찾아 수정합니다.

- `WorldMesh`: 바닥에 놓였을 때 표시할 Static Mesh.
- `WorldMeshScale`: 메시 크기.
- `NameKey` / `DisplayName`: 드롭 이름에 사용되는 FText.

`WorldMesh`가 비어 있거나 로드되지 않으면 기본 큐브를 사용합니다. 다른 아이템 외형을 표시하던 액터가 다시 초기화되어도 큐브로 되돌아갑니다.
아이콘, 착용한 무기 외형, 채집 지점과 작물의 외형은 각자의 기존 설정을 사용합니다.
드롭은 기존 F 줍기와 플레이시간 600초 소멸 규칙을 따릅니다.

## 테스트용 치트

`ICGiveGold`: 10,000G 추가. `ICGiveStarterWeapons`: 초보 무기 4종 지급.
`ICAddGameHours 2`: 게임시간 2시간, `ICAddGameHours 24`: 하루 경과.

뽑기 초기화 도구는 `Tools/Life/setup_gacha_and_drops.py`입니다. 기본 확률과 큐브 외형을 다시 지정하는 최초 설정용 도구이므로, DT를 수정한 뒤 일상적으로 재실행하지 마세요.
