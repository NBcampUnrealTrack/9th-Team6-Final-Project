개인 창고 전용 화면

가까이서 F로 창고를 열면 메뉴 탭과 분리된 창고 전용 창이 열립니다.
왼쪽: 해당 창고의 40칸. 오른쪽: 플레이어의 현재 가방.
창고는 각각 독립적이며, 추가 창고를 만들어도 기존 창고는 40칸 그대로입니다.

아이템을 누르면 아래 팝업만 표시합니다.
- 아이템 이름
- 아이템 설명 (무기는 기본 공격력·강화 정보 포함)
- < 선택 수량 / 이동 가능한 수량 >
- 창고로 이동 또는 인벤토리로 이동
- 뒤로

화살표 버튼 또는 A/D·좌/우 키로 수량을 조절합니다.
Enter로 이동하며, W/S·상/하 키로 이동/뒤로 버튼을 선택할 수 있습니다.
ESC는 팝업에서 목록으로 돌아가고, 목록에서는 창고를 닫습니다.
목록은 WASD·방향키로 이동하고 Tab으로 창고/가방을 전환합니다.

이 화면에는 소비아이템 사용, 장비 착용, 퀵슬롯 설정, 폐기 기능이 없습니다.
선택한 수량 전체를 넣을 공간이 부족하면 아무것도 이동하지 않습니다.
잠긴 아이템과 제작에 예약된 수량은 이동할 수 없습니다.
나눠 옮긴 스택은 원래 아이템의 등급·옵션을 유지합니다.

셀은 기존 WBP_IC_InventorySlot을 재사용합니다.

C++
UI/Life/ICStorageWidget: 독립 화면·정보 팝업·수량 조절.
ICPlayerController.OpenContainer: 메뉴 대신 창고 전용 WBP 열기.
ICInventoryComponent.TransferAmount: 선택 수량 이동.
ICInventoryComponent.GetTransferableCount: 잠금·예약을 제외한 이동 가능 수량.

기존 확장 저장 호환
예전에 40칸보다 컸던 창고는 로드할 때 기존 40칸의 빈자리에 먼저 재배치합니다.
들어가지 못한 아이템은 플레이어 근처 복구 상자에 저장하며, 이 복구 상자는 획득할 때까지 사라지지 않습니다.

검증
C++ 빌드, 관련 자동 검증 24개, 최종 UI 재검증 4개 통과.
실제 플레이에서 F로 열기, 5개 넣기·2개 꺼내기, 팝업 뒤로, 닫기, 재열기와 내용 보존을 확인했습니다.
